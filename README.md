# ПМ: тренажер

Навчальний вебтренажер для здобувачів ХНУВС (не є офіційним ресурсом університету):

- будова пістолета Макарова, неповне розбирання і збирання з анімацією;
- основи вогневої підготовки: ТТХ, патрон 9×18, прицілювання, заходи безпеки, затримки;
- трирівневий тренажер стрільби по БпЛА: калькулятор упередження, тренування з оцінюванням, моделювання секторної стрільби;
- тест на 15 питань.

Сайт: https://katyhavehamster-tech.github.io/article/

Тренажер є засобом реалізації методики, описаної в статті «Методика вогневої підготовки особового складу механізованих (піхотних) підрозділів до ураження малорозмірних повітряних цілей (БпЛА) стрілецькою зброєю з урахуванням досвіду бойових дій 2022-2026 років».
